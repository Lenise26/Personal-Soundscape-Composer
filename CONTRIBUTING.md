# Contributing

1. Create a focused branch for each change.
2. Use modern JavaScript modules and keep shared logic small and testable.
3. Escape or safely bind any user-controlled text before rendering it into HTML.
4. Add or update tests for user-visible behavior and data-model changes.
5. Run `npm test`, `npm run check`, and `npm run build` before opening a pull request.
6. Do not add third-party audio files without clear commercial usage rights and attribution requirements.
7. Keep included sample business/location data fictional or generic and U.S.-focused for this repository.
